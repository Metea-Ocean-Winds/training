# Linux Beginner to Wizard

Five-session Linux training, from beginner to administrator.

## Structure

### Beginner

1. [Session 1: Linux fundamentals](sessions/linux_session_1.md)

2. [Escape Room: Basic commands + ownership and permissions](sessions/escape-room/linux_escape_room.md)

### Intermediate

5. [Session 3: Flashback & shell power-ups](sessions/linux_session_3.md)

6. [Practice: Flashback exercises](sessions/flashback/session_3_practice_exercise.md)

7. [Session 4: Bash scripting & crontab](sessions/linux_session_4.md)

8. [Practice: Script automation](sessions/script_automation/session_4_practice_exercise.md)

9. [Session 5: Users, groups, sudoers, partitions & mounting](sessions/linux_session_5.md)

10. [Practice: Team onboarding & system audit](sessions/sysadmin_onboarding/session_5_practice_exercise.md)
